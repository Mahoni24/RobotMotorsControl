   Управление двигателем робота

## Создание проекта
  Открываем терминал, в папке *Project* создаем путь для локального репозитория **mkdir RobotMotorsControl** , переходим в созданную папку. 

  КОмандами **git config --global user.name** и **git config --global user.email** устанавливаем наши имя пользователя и почтовый ящик.

  Командой **git init** создал репозиторий в нашей директории, и командой **git status** убедился что репозиторий пустой

  Сделал скриншот, командой **cp** скопировал скрин в папку с проектом. Командой **git status** убедился, что скрин появился в *Untracked fail*. Командой **git add** добавили наш скрин в область *stage*. Далее командой **git commit -m** с описанием делаем первый коммит проекта.

## Создание удаленного репозитория и подключение к нему
  На *Github* создаем новый репозиторий. И создаем пароль-токен для подключения к нашему репозиторию. В терминале командой **git remote add origin** с сылкой на репозиторий в *Githab*, настраиваем наш сетевой репозиторий на ноутбуке. Командой **git remotr show** убеждаемся что появился новый сетевой репозиторий с именем *origin*. Командой **git remotr show origin** привязываемся к репозиторию на *github*. Затем командой  **git push -u origin master** передаем данные с локального репозитория на удаленный. Смотрим *github* там появился наш скрин.

  В терминале перешел в корневой каталог и там запустил команду **git clone** ввел имя пользователя и пароль-токен наш проект скопировался в корневой каталог. Но перешел обратно в рабочую папку проекта */Project/RobotMotorsControl* где продолжил работу.

## Создание новой ветки проекта
  Командой **nano motor_control.py** создаем Python файл и пишем скрипт для управления двигателем робота, сохраняем его. Так же командой **nano_README.md** создаем текстовый	файл куда будем вписывать заметки по проекту. 

  Далее командой **git add -A** добавляем наши файлы в *stage* область. Командой **git commit** делаем второй коммит нашего проекта. Далее командой **git push** отправляем данные на сервер.

  Создаем новую ветку проекта, запускаем команду **git branch Step_speed**. И командой **git branch** убеждаемся в появлении новой ветки. Командой **git checkout Step_speed** переходим на нашу ветку, убеждаемся в этом опять. Через *nano* дорабатываем наш код *motors_control.py* и заношу все шаги в файл *README.md*. 
   Далее командами **git add** и **git commit** делаем комит в нашей ветке и командой **git push --set-upstream origin Step_speed** добавляем новую ветку на сервер.
